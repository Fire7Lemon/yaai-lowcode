## 1. 仓库形态

- **本仓库（`yaai-lowcode`）**：Vue 3 + Vite + TypeScript + Element Plus **后台管理与低代码编辑器**，已接入真实 HTTP。
- **前台官网**：由 **成员 4** 在独立目录或仓库实现；消费菜单 / 页面 / 版本 / 节点树 / 组件定义 / 数据绑定（见 **[前台接入后台低代码说明](../02_前台对接/前台接入后台低代码说明.md)**）。

## 5. 环境与路径提醒
