# 管理员界面新增功能说明

## 1. 本轮范围

- 成员3职责扩展到管理员后台前端页面实现（仍在 `yaai-lowcode` 项目内）。
- 本轮新增两个管理页面：
  - 会员审核
  - 会员订单查看

## 2. 会员审核页面

- 页面路由：`/member-audit`
- 使用真实后端接口：
  - `GET /member/audit/single/list`
  - `GET /member/audit/company/list`
  - `POST /member/audit/pass?memberId=xxx`
  - `POST /member/audit/reject?memberId=xxx`
- 页面支持：
  - 个人会员待审核列表
  - 单位会员待审核列表
  - 查看详情（对当前列表行做详情弹窗）
  - 审核通过/拒绝（带确认弹窗）

## 3. 会员订单查看页面

- 页面路由：`/member-orders`
- 页面命名为“会员订单查看”，不宣称完整“缴费管理”。
- 使用真实后端接口：
  - `GET /member/order/list?memberId=xxx`
  - `GET /member/order/detail?outTradeNo=xxx`
- 当前能力说明：
  - 仅支持按 `memberId` 查询订单
  - 不支持管理员全量分页
  - 不支持按状态、关键字、年份筛选

## 4. 接口限制与后续建议

- 订单接口当前限制：仅支持 `memberId` 条件查询，不支持管理员全量列表。
- 要实现完整缴费管理，建议后端补充最小接口：

`GET /member/admin/order/list`

建议参数：

- `current`
- `size`
- `keyword`
- `status`
- `year`

建议返回字段：

- `outTradeNo`
- `memberId`
- `memberNo`
- `memberName`
- `memberCategoryName`
- `amount`
- `status`
- `paymentMethod`
- `createdAt`
- `paidAt`
- `expireTime`

## 5. 不变更项

- 本轮不修改数据库。
- 本轮不修改后端代码。
- 本轮不影响现有低代码编辑器与既有模块。
