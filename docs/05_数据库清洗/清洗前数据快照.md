# 清洗前数据快照（真库 / 联调 HTTP GET）

> **用途**：在执行任何写库、批量 API、SQL 变更前，对「当下真数据」留影；与 [数据库清洗候选清单.md](./数据库清洗候选清单.md)、[后台API修正操作清单_待确认.md](./后台API修正操作清单_待确认.md) 交叉使用。  
> **约定**：每条 **curl** 直连业务路径 **`http://127.0.0.1:9876/...`**（**不要** **`/api`**），且必须带 **`--max-time 10`**。  
> **component_key 白名单**：[component_key白名单.md](../01_设计基线/component_key白名单.md)。
