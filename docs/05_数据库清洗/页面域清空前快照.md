# 页面域清空前快照

> **快照时间（HTTP GET）**：文档根据 **`curl.exe --max-time 10`** 直连 **`http://127.0.0.1:9876`**（无 `/api`）拉取。**本轮拉取：`success:true`。**  
> **说明**：  
> - 本快照仅用于记录**执行清空前**的页面域相关状态。  
> - **不是**完整数据库备份；**不提供**等价整库回滚。  
> - 覆盖范围：**menus / pages / page_version / page_node / page_template / reusable_fragment** 等与页面链路关联的数据（经 HTTP 可读部分）。  
> - **本轮不执行删除、不写库。**  
>
> **`component_key` 前台白名单**（用于下文「componentKey 不在白名单」计数）：  
> `page_container`、`hero_banner`、`notice_list`、`quick_links`、`home_services`、`home_events`、`news_list`、`home_shortcuts`、`friend_links`、`rich_text`。  
>
> **附**：完整响应 JSON 请团队另存工单附件（不建议把整包贴进 git）；本节为**结构化摘要**。

## 7. page_node 快照

对 **§6 中每一个 versionId** 执行：

```bash
curl.exe --max-time 10 "http://127.0.0.1:9876/page-versions/{versionId}/node-tree"
```

**统计口径**  

- **根节点数量**：`parentId == null`（或等价）的节点条数。  
- **componentKey 为空**：`componentKey === null`。  
- **不在白名单**：`componentKey` 非 null 且**不在**白名单集合（空键不计入本列）。  
- **parentId 断链**：存在 `parentId` 指向的版本内**不存在的 id**。

| versionId（pageId） | nodes 数量 | 根节点数量 | componentKey 为空 | 不在白名单 | parentId 断链 | 是否拟删除（随版本一键删） | 删除原因摘要 |
