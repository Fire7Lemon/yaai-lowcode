## 10. 后端级联 / 接口行为观察

1. **`DELETE /pages/{id}`**：随后 **`GET /pages/{id}/versions`** 为空；**`GET /page-versions/{旧versionId}/node-tree`** 返回 **`PAGE_VERSION_NOT_FOUND`** —— **符合**「删页即删版本与节点」预期（以 HTTP 行为为准）。  
2. **`DELETE /page-templates/{id}`** / **`DELETE /reusable-fragments/{id}`**：主体删除后，旧 **node-tree** **GET** 返回 **NOT_FOUND**。  
3. **业务错误码**：部分 **GET** 在资源不存在时仍可能 **HTTP 200** + **`success:false`**，验收以 **`code` / `success`** 为准。
