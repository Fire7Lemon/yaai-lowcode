## 2. 前台消费链路

推荐实现顺序（与 [前台接入后台低代码说明.md](./前台接入后台低代码说明.md) §3 一致）：

1. **`GET /menus`**（或封装为 `public-menu.ts`）  
   - 组装导航；`urlType=page` 时取 `pageId`。
2. **`GET /pages`**（或封装为 `public-page.ts`）  
   - 建立 `pageId → page` 与 `path → page` 索引。
3. 用户进入路由 → 用 **`route.path`** 匹配 **`page.path`**（注意 `/about/introduction` 等精确匹配）。
4. 读取匹配到的 **`page.currentVersionId`**。
5. **`GET /page-versions/{currentVersionId}/node-tree`**（或封装为 `public-node-tree.ts`）  
   - 响应为 **camelCase**；`data.nodes` 为 **平铺数组**。
6. **flat nodes → tree**：按 **`parentId`**（`null` 为根）、**`slotName`**、**`sortOrder`** 组装。
7. **`NodeRenderer`** 递归渲染；按 **`componentKey`** 查 **`component-map.ts`**。
8. **`propsJson` / `styleJson` / `layoutJson`** 在运行时 **`JSON.parse`**，解析失败需兜底为空对象，避免白屏。
9. 未知 **`componentKey`** → **`UnknownComponent`** 兜底，**不得**抛错导致整页崩溃。

**接口基址**：

| 场景 | 基址 |
|------|------|
| curl 直连后端 | `http://127.0.0.1:9876/...`（**不加** `/api`） |
| YAAI / Vite 开发 | 经代理 **`/api/...`**（以项目 `VITE_API_BASE_URL` 为准） |
