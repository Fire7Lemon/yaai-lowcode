# 首页三个片段：后台配置与展示端对接说明

> 面向 **低代码后台（成员三）**：在首页 `page_node` 上配置 `componentKey` 与 `propsJson`。  
> 展示端从节点读取配置，**不再写死**学会活动 / 服务矩阵 / 友情链接数据。

---

## 1. 总览

| componentKey    | 前台组件        | 配置方式 | dataBindingId |
|-----------------|-----------------|----------|---------------|
| `home_events`   | HomeEvents      | `propsJson.contentIds` | **不需要** |
| `home_services` | HomeServices    | `propsJson.contentIds` | **不需要** |
| `friend_links`  | HomeFriendLinks | `propsJson.links`      | **不需要** |

节点字段：

- `componentKey`：组件标识
- `propsJson`：字符串，内容为 JSON（见下文 schema）

---

## 2. 核心规则：contentId

**学会活动**、**服务矩阵** 不再按分类拉列表，也不再在 propsJson 里写标题/图标/链接。

成员三只需在 `propsJson.contentIds` 中填写 **新闻 id 数组**（即 contentId）。展示端会：

1. 按顺序对每个 id 请求 `GET /news/{id}`
2. 用返回的新闻数据渲染首页卡片
3. 用户点击卡片 → 跳转 `/content/{id}` 详情页

| 板块 | contentIds 对应新闻字段 | 卡片展示 | 点击跳转 |
|------|-------------------------|----------|----------|
| 学会活动 | title、coverImage、publishTime、source | 标题 / 封面 / 日期 / 来源 | `/content/{id}` |
| 服务矩阵 | title、summary、coverImage | 标题 / 摘要 / 封面作图标 | `/content/{id}` |

**空数据：** `contentIds` 为空、未配置、或全部 id 无效时，展示 **「暂无活动」/「暂无服务」**，**无内置默认内容**。

---

## 3. `home_events` — 学会活动

### 3.1 节点配置

```json
{
  "componentKey": "home_events",
  "propsJson": "{\"title\":\"学会活动\",\"moreLink\":\"/conference\",\"tag\":\"学术会议\",\"contentIds\":[101,102,103]}"
}
```

### 3.2 propsJson Schema

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 区块标题，默认「学会活动」 |
| moreLink | string | 否 | 「更多精彩」链接，默认 `/conference` |
| tag | string | 否 | 卡片角标，默认「学术会议」 |
| **contentIds** | **number[]** | **是** | 新闻 id 列表，顺序即首页展示顺序 |

### 3.3 成员三如何维护

1. 在内容管理里创建/发布活动类新闻，记下每条新闻的 **id**
2. 在首页 `home_events` 节点的 `propsJson.contentIds` 中填入这些 id
3. 增删改活动：只改 id 数组，无需改标题/封面等（以新闻本身为准）

---

## 4. `home_services` — 服务矩阵

### 4.1 节点配置

```json
{
  "componentKey": "home_services",
  "propsJson": "{\"title\":\"服务矩阵\",\"moreLink\":\"/services\",\"contentIds\":[201,202,203,204]}"
}
```

### 4.2 propsJson Schema

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 区块标题，默认「服务矩阵」 |
| moreLink | string | 否 | 「查看全部」链接，默认 `/services` |
| **contentIds** | **number[]** | **是** | 新闻 id 列表，每条对应一个服务卡片 |

### 4.3 卡片字段映射

| 卡片字段 | 新闻字段 |
|----------|----------|
| 标题 | title |
| 描述 | summary（为空则不显示描述） |
| 图标 | coverImage（相对路径自动补 `/`） |
| 链接 | `/content/{id}` |

### 4.4 空数据

`contentIds` 为空或未配置时，展示 **「暂无服务」**，无内置默认 4 项。

---

## 5. `friend_links` — 友情链接

友情链接仍由 propsJson 静态配置（站外链接），**不使用 contentId**。

### 5.1 节点配置

```json
{
  "componentKey": "friend_links",
  "propsJson": "{\"title\":\"友情链接\",\"subtitle\":\"外部协作单位与学术合作机构\",\"links\":[{\"name\":\"中国人工智能学会\",\"url\":\"http://www.caa.org.cn/\"},{\"name\":\"云南大学\",\"url\":\"https://www.ynu.edu.cn/\"}]}"
}
```

### 5.2 propsJson Schema

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| title | string | 否 | 区块标题 |
| subtitle | string | 否 | 副标题 |
| links | array | 是 | 友情链接列表 |

**links[] 每项：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 显示名称 |
| url | string | 是 | 跳转地址（`http(s)://`，新窗口打开） |

### 5.3 空数据

`links` 为空或未配置时，展示 **「暂无链接」**，无内置默认链接。

---

## 6. 成员三操作清单

1. 准备活动/服务类新闻，确认已发布并记录 **新闻 id**
2. 在首页 `page_node` 放置三个节点，填写对应 `componentKey`
3. **`home_events`**：`propsJson.contentIds` = 活动新闻 id 数组
4. **`home_services`**：`propsJson.contentIds` = 服务新闻 id 数组
5. **`friend_links`**：`propsJson.links` = 站外链接数组
6. 发布页面版本后，展示端自动读取

## 8. 接口说明（展示端已实现）

| 用途 | 接口 |
|------|------|
| 按 contentId 拉单条新闻 | `GET /news/{id}` |
| 详情页 | 路由 `/content/{id}` |

`contentIds` 中某个 id 不存在或未发布时，该条跳过，其余正常展示；全部失败则显示空状态。
