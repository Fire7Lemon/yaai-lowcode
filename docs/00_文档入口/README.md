# `docs/` 文档总入口

本文件为 **`yaai-lowcode/docs`** 的**导航起点**。业务契约、前台对接说明、联调交付与数据库清洗等材料已按子目录收口；请以本文件与 **`文档索引.md`** 为准进入具体文档。

**工程脚手架说明**仍在仓库根目录 [`README.md`](../../README.md)（安装、`npm run dev` 等）。

## 5. 重要约束（全员）

| 条目 | 说明 |
|------|------|
| **浏览器 / Vite** | 请求前缀 **`/api/...`**（与 `VITE_API_BASE_URL` 一致）。 |
| **curl 直连后端** | **`http://127.0.0.1:9876/...`**（路径随环境调整），**不要**在端口后再加 **`/api`**，否则会常见 **`SYSTEM_ERROR` 误判**（详见 [`03_联调交付/联调总进度.md`](../03_联调交付/联调总进度.md)）。 |
| **数据模型** | 以 **`01_设计基线/数据库设计_v6.0_平台型低代码版.md`** 为当前正文标准。 |
| **前端类型 / 表单** | 语义保持 **`snake_case`**，与数据库字段名对齐。 |
| **后端读写常见形态** | 多为 **camelCase**；由 **`src/api/*`** 做适配（成员 4 自建前台 API 层时同理）。 |
| **`props_json` 等 JSON 字段** | 契约层仍为 **`string | null`**；渲染时再 **`JSON.parse`** 并做好兜底。 |
| **真实模式** | **禁止**用 mock/fallback **假成功** 掩盖接口 **`success:false`**。 |
